      What it converts here

      MarkItDown's converters are the same ones the command line uses — this page just runs them in WebAssembly. Two of them need programs that do not exist in a browser, and rather than hand you an empty file, the page says so.

      How this works

      1. Real CPython, not a rewrite

        Pyodide is CPython compiled to WebAssembly. The page installs a wheel built from packages/markitdown in this repository, so the converter running on your file is this project's actual source — not a JavaScript reimplementation of it.

      2. Two dependencies get stand-ins

        MarkItDown detects file types with magika, a neural classifier that needs ONNX Runtime; pdfplumber pulls in pypdfium2 for page rendering. Neither has a WebAssembly build. The site substitutes a signature-based sniffer for the first and an import stub for the second — MarkItDown never renders PDF pages, so nothing is lost. Text and table extraction are untouched.

      3. Loaded only when needed

        The cold start is the Python runtime plus a few hundred kilobytes. Heavier converters arrive on demand: opening a spreadsheet is what fetches pandas, opening a PDF is what fetches pdfminer. Convert only HTML and you never pay for either.

      4. Nothing leaves the tab

        There is no API and no origin server doing work — the deployment is static files. Your document is read into a WebAssembly heap in your own browser and stays there.

      Want the full thing?

      Images and audio need exiftool and ffmpeg; captions and transcripts need a model. Those are a local install away. 

      # the converters this page runs, plus the ones it can't
pip install 'markitdown[all]'

# one file
markitdown paper.pdf > paper.md

# or from Python
from markitdown import MarkItDown
MarkItDown().convert("paper.pdf").markdown
